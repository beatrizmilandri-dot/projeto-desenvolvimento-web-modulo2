## 📝 Descrição do Projeto
Aplicação web dinâmica e responsiva desenvolvida para a avaliação prática do Módulo 2 da disciplina de Desenvolvimento Web com Frameworks e HTML/CSS. 

O projeto foi construído focando na estruturação semântica de páginas em HTML5 (para melhor acessibilidade e indexação em motores de busca), estilização responsiva com CSS3 adaptável a múltiplos tamanhos de tela (desktops, tablets e smartphones), e na utilização de um framework web moderno para modularização do código e componentização da interface.

---

## 🚀 Tecnologias Utilizadas
- **HTML5:** Marcação semântica (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`), acessibilidade e suporte a leitores de tela.
- **CSS3:** Estilização adaptável utilizando CSS Flexbox, CSS Grid Layout e Media Queries para responsividade.
- **Framework Web:** Bootstrap / React.js (Estruturação de componentes visuais e padronização da interface).
- **Git & GitHub:** Versionamento do código-fonte e hospedagem da aplicação.
